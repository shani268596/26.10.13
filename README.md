# 🎯 MemoryQ (메모리큐) - 시험 암기 마스터

> 시험 직전 완벽한 암기를 도와주는 **5지선다 및 OX 퀴즈 생성·풀이 전문 웹 애플리케이션**입니다.  
> 별도의 복잡한 설치 과정 없이 `index.html` 파일만 열면 브라우저(Chrome, Edge, Safari 등)에서 즉시 구동됩니다.

---

## ✨ 핵심 기능 소개

### 1. ✍️ 2대 필수 시험 문제 풀이 모드
- **5지선다 모드 (Choice 5)**:
  - 수능, 공무원, 자격증 시험에 필수적인 1번~5번 선택지 풀이
  - 키보드 숫자키 `1`, `2`, `3`, `4`, `5` 단축키 지원으로 초고속 풀이 가능
  - 오답 선택 시 즉시 붉은색 경고 및 정답 보기 녹색 하이라이트
- **스피드 OX 퀴즈 모드 (True / False)**:
  - 헷갈리는 핵심 기출 지문을 1초 만에 판별하는 스피드 암기 특화 모드
  - 단축키 `O` (또는 `1`), `X` (또는 `2`) 지원
  - 큼직하고 직관적인 터치 버튼으로 모바일에서도 쾌적하게 학습 가능
- **3단계 학습 방식**:
  - **📝 연습 모드**: 한 문제 풀 때마다 즉시 정답 및 상세 해설 확인
  - **🃏 플래시카드 암기 모드**: 3D 카드 뒤집기(Space / 클릭)로 문제-답 연상 훈련
  - **⏱️ 실전 모의고사 모드**: 카운트다운 타이머와 함께 일괄 풀이 후 최종 성적표 확인

---

### 2. ✨ 스마트 퀴즈 생성기 (Quiz Generator)
- **🤖 스마트 텍스트 자동 파서**:
  - 교재 요약본이나 시험 정리 노트를 붙여넣으면 OX 및 5지선다 문제를 자동으로 인식하여 문제집으로 변환합니다.
- **💡 AI 프롬프트 템플릿**:
  - ChatGPT, Claude 등에 교재를 복사해 넣고 바로 사용할 수 있는 원클릭 프롬프트 제공
- **✍️ 직접 문제 추가**:
  - 문제 지문, 5개 보기, 정답, 상세 해설, 해시태그를 자유롭게 등록 가능

---

### 3. ❌ 스마트 오답노트 & 암기 추적 시스템
- **자동 오답 수집**: 틀린 문제는 자동으로 오답노트에 기록됩니다.
- **오답노트만 집중 풀기**: 틀린 문제들만 모아 정답률 100%가 될 때까지 무한 반복 훈련 가능!
- **암기 완료 체크**: 완전히 외운 문제는 오답노트에서 한 번의 클릭으로 졸업 처리
- **⭐ 중요 문제 북마크**: 헷갈리는 지문 별표 표시 후 모아보기

---

### 4. 📚 기본 탑재 프리셋 문제집 (즉시 테스트 가능)
- 🇰🇷 **한국사 핵심 기출 암기 노트** (5지선다 & OX)
- ⚖️ **헌법·법률 및 일반상식 필수 퀴즈** (5지선다 & OX)
- 💻 **IT · 컴퓨터 일반 & 정보처리기사 핵심** (5지선다 & OX)

---

### 5. 🎨 프리미엄 UI & 오디오 효과
- **다크/라이트 모드**: 눈의 피로도를 낮추는 세련된 다크 테마 기본 지원
- **Web Audio 합성 사운드**: 정답/오답/카드 플립 시 깔끔한 효과음 (외부 음원 파일 다운로드 불필요)
- **Confetti 폭죽 효과**: 정답 연타 및 100점 달성 시 터지는 Canvas 축하 효과
- **JSON 백업/복원**: 만든 문제집을 JSON 파일로 저장하거나 친구에게 공유 가능

---

## 🚀 실행 방법

1. `index.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge 등)로 엽니다.
2. 상단 메뉴에서 원하는 기능을 선택하여 학습을 시작하세요:
   - **퀴즈 풀기**: 바로 시험 문제 풀기
   - **퀴즈 만들기**: 나만의 교재 텍스트를 붙여넣어 새 문제집 생성
   - **오답노트**: 틀린 문제 집중 복습
   - **문제집 보관함**: 과목별 문제집 전환 및 백업

---

## ⌨️ 키보드 단축키 안내

| 키 | 동작 |
|---|---|
| **1 ~ 5** | 5지선다 보기 1번 ~ 5번 선택 |
| **O / X** | OX 퀴즈 답변 선택 |
| **Space** | 플래시카드 앞/뒷면 뒤집기 |
| **Enter / →** | 다음 문제로 이동 |
| **←** | 이전 문제로 이동 |
